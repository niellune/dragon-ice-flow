# raw/ — Immutable Sources

Drop sources here. **Do not modify.**

- PDFs (papers, reports)
- Markdown (articles clipped with Obsidian Web Clipper or similar)
- Transcripts (YouTube, podcasts, meetings)
- Plain text, exported chats, notes

This folder is the **source of truth**. The wiki is derived from these files. If the wiki is wrong, you re-derive from here — not the other way around.

## Filename convention

`YYYY-MM-DD_short-slug.ext` — e.g. `2026-04-04_karpathy-llm-wiki.md`

The date is when you added the source (or when it was published, your choice — pick one and stick with it).
